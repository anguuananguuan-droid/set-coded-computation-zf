3 Acceptance conditions

The homepage identifies the independent computation session and its limits.
Current documentation matches the actual session and theory dependencies.
Historical reviews remain retrievable and are not represented as current
specifications. All project theories remain registered, public document
references resolve, and the independent core and complete repository build
successfully.

Routine document revision, path migration, source checks, and removal of
unnecessary build dependencies are within scope. A change to a mathematical
definition, theorem claim, license, or attribution requires a separately
identified justification.
