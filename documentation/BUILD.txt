REPRODUCTION

1 ENVIRONMENT

The supported release is Isabelle2025-2. Set_Coded_Computation_ZF uses
Isabelle/ZF and the bundled ZF-Induct session. Set_Coded_Invariance_ZF and
the model extensions use the AFP snapshot dated 6 February 2026.

https://isabelle.in.tum.de/website-Isabelle2025-2/
https://isa-afp.org/release/afp-2026-02-06.tar.gz

2 INDEPENDENT COMPUTATION SESSION

Run from the repository root with Isabelle on the executable search path.

    isabelle build -v -c -D Turing_Machines_ZF/Core Set_Coded_Computation_ZF

3 INVARIANCE SESSION AND COMPLETE REPOSITORY

Extract the AFP snapshot and register its theory directory. Replace the
example absolute path with the actual path.

    isabelle components -u /absolute/path/to/afp-2026-02-06/thys
    isabelle build -v -c -d Turing_Machines_ZF/Core -D Set_Coded_Invariance_ZF Set_Coded_Invariance_ZF
    isabelle build -v -D .

The five local sessions are Set_Coded_Computation_ZF, Turing_Machines_ZF,
Set_Coded_Invariance_ZF, Turing_Models, and Turing_Absoluteness. The first
depends only on Isabelle/ZF. The invariance session extends it and uses
Independence_CH. Turing_Models extends the invariance session. The extended
machine-program session is separate.

A slower machine may require fewer parallel workers and a longer timeout.
The following command clears and rebuilds the selected local sessions while
reusing unchanged external dependencies.

    isabelle build -v -c -j 1 -o threads=2 -o timeout=1800 -D .

A successful build returns exit status 0. Without the clearing option,
Isabelle may reuse unchanged session products. Neither mode establishes that
the definitions express an intended informal theorem.

4 REPOSITORY CHECKS

The repository check validates local document references, session theory
membership, the independent core import boundary, and the absence of selected
proof escape tokens. It is a source check, not a proof checker.

    python3 scripts/check_repository.py
    git diff --check

5 SUBMISSION ARCHIVE AND DOCUMENT

The sole submission entry is Set_Coded_Halting_Invariance_ZF. Its export
uses submission/ROOT and the maintained development theories. Reproduce the
archive build using the commands in documentation/AFP.txt.

    bash scripts/package-afp-entry.sh

LuaLaTeX is required for the PDF. A proof build without document=pdf does
not verify document generation. CI builds the extracted archive with both
the complete proof document and a proof outline.

The document build repeats LuaLaTeX until the auxiliary, contents, and
bookmark files stop changing. It fails if they do not stabilize within
six passes. Successful PDF generation alone does not establish correct
contents-page references.

6 CONTINUOUS INTEGRATION

The workflow in .github/workflows/isabelle.yml checks the repository, builds
the independent core before registering AFP, and builds all five sessions.
It then exports the nineteen-theory submission and builds that archive with
its proof document. The saved submission heap is checked for undischarged
hypotheses in the six principal results and oracle dependencies throughout
its named proof closure. AFP mandatory style checks run on the extracted
entry. Any failure rejects the run.
The Linux distributions are installed by scripts/install-ci.sh. Actions are
pinned to commit identifiers and build logs are attached to each run.

The following SHA256 values are used by the installer.

7 SUBMISSION PROOF AND STYLE CHECKS

Build the exported entry with a saved heap before inspecting dependencies.
The ML check is maintained outside the submission theories.

    isabelle build -b -D output/afp-entry/Set_Coded_Halting_Invariance_ZF
    isabelle ML_process -d output/afp-entry/Set_Coded_Halting_Invariance_ZF -l Set_Coded_Halting_Invariance_ZF -f scripts/check_submission_proofs.ML

This check rejects theorem oracle dependencies, including skipped proofs.
It does not judge semantic adequacy or establish a new consistency result.

The linter revision is c9983adc5c51a6455f702bb58c9f960d425a2af3.
Download that revision from the repository below and register linter_base.
Replace the example absolute path with the extracted directory.

    isabelle components -u /absolute/path/to/isabelle-linter-c9983adc5c51a6455f702bb58c9f960d425a2af3/linter_base
    isabelle lint -o lint_bundles=afp_mandatory -f error -O output/afp-lint.txt -D output/afp-entry/Set_Coded_Halting_Invariance_ZF

An empty report records no findings from the selected checks. It does not
replace mathematical review. The Linux installer pins the linter archive
to SHA256 83dc386d6e9dcbfa9f820abddac31c1bedffa46f1f74265a8ccf9007ff9ca2f1.
