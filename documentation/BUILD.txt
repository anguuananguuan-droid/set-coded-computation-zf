REPRODUCTION

1 Environment

The supported release is Isabelle2025-2. Set_Coded_Computation_ZF uses
Isabelle/ZF and the bundled ZF-Induct session. Turing_CH and Turing_Models
require the AFP snapshot dated 6 February
2026.

https://isabelle.in.tum.de/website-Isabelle2025-2/
https://isa-afp.org/release/afp-2026-02-06.tar.gz

2 Independent computation session

Run from the repository root with Isabelle on the executable search path.

    isabelle build -v -D Turing_Machines_ZF/Core Set_Coded_Computation_ZF

For a fresh build of that session, clearing its existing build product first.

    isabelle build -v -c -D Turing_Machines_ZF/Core Set_Coded_Computation_ZF

3 Complete repository

Extract the AFP snapshot and register its theory directory. Replace the
example absolute path with the actual path.

    isabelle components -u /absolute/path/to/afp-2026-02-06/thys
    isabelle build -v -D .

The four local sessions are Set_Coded_Computation_ZF, Turing_Machines_ZF,
Turing_CH, and Turing_Models. Turing_Machines_ZF and Turing_CH each extend
Set_Coded_Computation_ZF. Turing_Models extends Turing_CH. The CH research
does not depend on the extended machine programs.

The computation sessions have a 300-second timeout. Turing_CH has a
900-second timeout because its Isabelle/ZF and AFP imports are rechecked
inside that session. A slower machine may require fewer parallel workers
and a longer timeout. The following command clears and
rebuilds the selected local sessions while reusing unchanged external
dependencies.

    isabelle build -v -c -j 1 -o threads=2 -o timeout=1800 -D .

A successful build returns exit status 0. Without the clearing option,
Isabelle may reuse unchanged local session products. Neither mode establishes
that the definitions express an intended informal theorem.

4 Repository checks

The repository check validates local document references, session theory
membership, the independent core import boundary, and the absence of selected
proof escape tokens. It is a source check, not an Isabelle parser or a proof
checker.

    python3 scripts/check_repository.py
    git diff --check

5 Continuous integration

The workflow in .github/workflows/isabelle.yml first checks the repository,
then builds the independent core before registering AFP, and finally builds
all four sessions. The Linux distributions are installed by
scripts/install-ci.sh. Actions are pinned to commit identifiers and build logs
are attached to each run.

The following SHA256 values are used by the installer.

identifies the snapshot used by this project. Dependencies are downloaded
separately and are not redistributed in the repository.
