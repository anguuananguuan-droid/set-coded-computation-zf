AFP CANDIDATE

1 LIBRARY AND RESULT

Set_Coded_Turing_Machines provides a set-coded deterministic machine model,
finite execution, observational tape equivalence, and internal halting
formulas. For each transitive ZF set model, the closed formula
halt_sentence(P,x) is true in that model exactly when the well-formed
machine P halts on the finite input x. The proofs also apply directly in
M_ZF1_trans. No model existence or choice assumption is needed for the
conditional satisfaction theorem.

Numerical coding supplies a primitive-recursive constructor for the code
of halt_sentence(decode_machine(e),numeral_input(n)), with independent
natural-number arguments e and n. Formula-code injectivity connects any
formula bearing that code to the satisfaction theorem. The self-input
constructor is the diagonal instance. The interface does not claim a
general machine compiler or a universal machine.

The operational example proves a scanning program's result for every unary
input and transfers it to a padded representation. The model example uses
that program theorem through the satisfaction interface. The library guide
in documentation/COMPUTATION.md specifies imports and intended use.

Step-closed invariants provide a nonhalting rule. Observationally equal
inputs have identical halting behaviour and agree on internal halting
truth. An external client checks these interfaces against the exported
archive using a program that halts exactly on the empty unary input.

2 DEPENDENCIES AND APPLICATIONS

The maintained entry is thys/Set_Coded_Turing_Machines. Its ROOT declares
seventeen theories in one session. The archive copies those sources and
ROOT unchanged. The public namespace is identical in repository and archive.

The operational theories and their example depend only on bundled ZF.
Numerical machine certificates additionally use ZF-Induct. The independent
computation check exercises this seven-theory source closure without AFP.

The complete session retains Independence_CH as parent because
M_ZF1_trans and the full-ZF interpretation are supplied by that entry.
The candidate imports ZF_Trans_Interpretations, not the CH disagreement
application. It neither proves independence of CH nor uses it as a premise
of the halting theorem. Eliminating this upstream package dependency would
require a separate reorganisation of the upstream model interfaces.

Research/Invariance contains decision semantics, self-halting
undecidability, and primitive-recursive reductions to invariant sentence
codes. Other research sessions retain numeric evaluation, bounded
workspaces, larger programs, and arithmetic extensions. These sources are
maintained and checked, but are not included in the candidate archive.

3 CONTRIBUTION AND EVIDENCE

The contribution is a reusable formal interface from explicit machine
execution to internal satisfaction and effective sentence construction in
Isabelle/ZF. The operational design follows Universal_Turing_Machine.
Model closure and satisfaction use the existing ZF model libraries. No new
classical theorem or priority claim is made.

The exported archive is the acceptance target. It shall build with its
300-second ROOT timeout. Proof-dependency checks cover the public endpoints
and candidate fact closure. The linter is validated with negative controls.
Both document variants shall compile with converged references and pass
layout inspection. documentation/BUILD.txt gives the commands.

Verification applies to the checked source revision and archive checksum.
Historical verification records do not certify a later source reorganisation.
