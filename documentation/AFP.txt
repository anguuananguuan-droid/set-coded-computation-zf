AFP CANDIDATES

1 COMPUTATION

Set_Coded_Computation_ZF is the independent computation library in
Turing_Machines_ZF/Core. Its eleven theories depend on Isabelle/ZF and the
distribution's ZF-Induct session. They establish set-coded machine semantics,
numerical evaluation with primitive-recursive finite-step certificates,
self-input halting undecidability, and tape observation and workspace results.

2 INVARIANCE

Set_Coded_Invariance_ZF extends the computation library and depends on the
AFP entry Independence_CH. Its eleven theories establish a closed internal
halting sentence, its satisfaction theorem for transitive ZFC set models,
an injective code for formulas, and primitive-recursive syntax transformations.
Under existence of a countable transitive ZFC set model, both self-input
halting and its complement primitive-recursively many-one reduce to codes of
closed sentences invariant across all transitive ZFC set models.

The second candidate depends on the first. The archive and submission order
need to be agreed with AFP editors because the computation library has not
been accepted as an AFP entry. Neither candidate claims a general machine
compiler or the full arithmetic-truth reduction of the EPQ paper.

3 VERIFICATION

Use Isabelle2025-2 and the AFP snapshot dated 6 February 2026. From the
repository root, build the computation session independently, then register
the AFP snapshot and build the invariance session.

    isabelle build -v -c -D Turing_Machines_ZF/Core Set_Coded_Computation_ZF
    isabelle components -u /absolute/path/to/afp-2026-02-06/thys
    isabelle build -v -c -d Turing_Machines_ZF/Core -D Set_Coded_Invariance_ZF Set_Coded_Invariance_ZF

For proof documents, install LuaLaTeX and build each candidate with
document=pdf. The local proof builds verify the theories, not the PDF.

4 SUBMISSION UNITS

    bash scripts/package-afp-entry.sh core
    bash scripts/package-afp-entry.sh invariance

Each archive contains its own ROOT, theories, document/root.tex, and LICENSE.
The invariance archive declares the computation session as a dependency; it
does not duplicate its sources. Inspect both archives before submission.

5 REVIEW BOUNDARY

The five-action machine design follows the AFP entry Universal Turing Machine
in Isabelle/HOL. These candidates use set-coded Isabelle/ZF semantics.
External review is needed to assess novelty, maintainability, and suitability
for AFP. A successful repository build does not establish those judgments.
