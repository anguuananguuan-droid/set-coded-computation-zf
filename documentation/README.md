# Documentation

## 1 Library

[Library guide](COMPUTATION.md) covers imports, machine conventions,
program proofs, tape observations, halting sentences, and numerical codes.
[Build instructions](BUILD.txt) specify the supported environment and
commands for source, proof, archive, style, and document checks.

[Proof verification record](records/RV.011.txt) identifies the proof-source
revision, archive checksum, public build evidence, and published PDFs.
[Research and proof documents](../papers/README.md) provide the one-page
summary, proof outline, complete proof document, and EPQ paper.

## 2 Scope

[AFP candidate](AFP.txt) defines the library boundary and acceptance checks.
[Research extensions](RESEARCH.md) describes applications outside that
boundary, their remaining proof obligations, and the migration from earlier
theory namespaces. [Research audit](records/RV.010.txt) identifies the
proved interfaces and open objectives at main revision 6c1b42c.

## 3 Project records

[AI usage](AI_USAGE.txt) records authorship, tool participation, and
verification responsibilities. [Development records](history/README.md)
retain earlier instructions, reviews, source manifests, and build evidence.
The [EPQ production log](../papers/EPQ_Log.pdf) preserves the
candidate's project process in a reading copy. The [complete form](../papers/EPQ_Production_Log.pdf)
and [Word copy](../papers/EPQ_Production_Log.docx) remain available.
[Publication record](records/RV.012.txt) identifies the reading copy and
current document navigation. Historical claims apply to the revisions
recorded in those documents.

[Contribution rules](../CONTRIBUTING.txt) govern changes to the repository.
[Third-party notices](../THIRD_PARTY_NOTICES.txt) preserve applicable
license notices. The [EPQ paper](../papers/EPQ.pdf) supplies the
project's motivation and is separate from the library's verified results.
