# Papers and proof documents

## 1 Research summary

[Research summary](Research_Summary.pdf) presents the question, main theorem,
effective sentence construction, and scope in one page. The mathematical
source baseline is 6c1b42c. The summary is an introduction to the verified
development.

Rebuild the summary with `python3 scripts/build_research_summary.py` from
the repository root, with ReportLab and pypdf installed.

## 2 Formal proof documents

[Complete proof document](library/Set_Coded_Turing_Machines.pdf) contains
108 pages, including all candidate proofs.
[Proof outline](library/Set_Coded_Turing_Machines_Outline.pdf) contains
68 pages with the detailed proof and ML blocks omitted. It retains
definitions, statements, explanations, and references.

Both files were generated by Isabelle at revision 6c1b42c.
[RV.011](../documentation/records/RV.011.txt) records the build revision,
their provenance, and SHA256 values. They can be regenerated with the
[build instructions](../documentation/BUILD.txt).

## 3 Motivating paper

[Original EPQ paper](EPQ.pdf) examines the continuum hypothesis, model
invariance, and computability. Its Section V motivates the formalisation.
The paper is distinct from the generated proof documents. Its full
arithmetic-truth argument has not been formalised. The
[research guide](../documentation/RESEARCH.md) identifies the remaining
proof obligations.
